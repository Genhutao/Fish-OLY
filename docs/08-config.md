# 08 · 配置面

可配置性是"角色自主"卖点的一半。配置面必须进架构而非事后贴开关：**配置即内容（不可变 blob）、变更即命令事件、包络即产品承诺**。

## 1. 配置的架构形态

```cpp
// 配置对象 = 内容寻址不可变 blob + 分层合并
Effective(session, persona) = merge(
    platform_defaults,     // 进程流下发，仅运营
    world_config,          // 世界级覆盖（按 canon 寻址；fork 族/模板实例共享，Owner 设定）
    session_config,        // 会话级覆盖（Owner/Admin）
    persona_config         // 角色级覆盖（创建者/被授权角色）
);  // 使用点解析，每 loop 缓存；config.changed 通知热生效
```

- 变更 = 命令事件落在所属流（会话配置→会话流；角色配置→身份流），准入时权限检查 + 包络钳制（越界拒绝并写 denial）；
- 变更只是换一个 ContentId；
- **重放自动还原历史配置**（配置本身事件化）→ 确定性叙事完整；
- 配置可回滚 = 版本链；
- `decision.recorded` 附生效配置 ContentId → 行为可精确归因到参数值。

## 2. 可配置项总账

| 域 | 可配置项 | 作用域 | 调整者 | 平台包络 |
|---|---|---|---|---|
| 自治 | tick 周期、每拍决策数 K、τ_base、attention 权重 wᵢ、冷却档 H、streak 成本 k、沉默采样率、降级阶梯选择 | 会话 | Owner/Admin | K 上限、τ 下限（防刷屏） |
| 自治·人格档 | 外向度（τ 偏置）、话唠度（冷却×长度偏好）、主动性（dm/invite 意愿）、好奇心（读工具激进度） | 角色 | 创建者（角色按 §3 自调） | 心理可测范围 |
| 记忆 | 召回 TopK、sim/importance/recency 权重、WorkingSet 窗口 N、摘要/抽取触发周期、重要度半衰期、候选自动接受 vs 人工审阅 | 角色 / 分册 | 创建者 / 分册归属者 | 上限=配额 |
| 提示板 | 槽位预算再分配（限内滑动）、回复长度、语言与风格约束 | 角色 / 会话 | 创建者 / 会话 Admin | **Identity/Output 槽位地板锁死** |
| 网关 | 档位路由偏好、世界 token 预算（日/时）、付费降档许可、P2:P3 花费比 | 世界 / 主体 | 世界 Owner / 用户本人 | 平台配额天花板 |
| 用户自有体验 | 被打扰策略（谁可 dm_request、免打扰时段）、记忆分册审阅模式、数据导出/删除 | 主体 | 用户本人 | — |
| 运维/平台 | 包络上下限、饱和控制增益、复制窗口、审计保留期 | 进程 | 仅运营 | — |

**明确不可配置**（结构性）：权限超集不变量、canon 冻结、事件不可变、先持久后可见、安全槽位地板、内容护栏与分级、社交保护限流。这些写进包络本身——**包络是承诺，不是默认值**。

## 3. 角色自调的三级分类

| 级别 | 内容 | 规则 |
|---|---|---|
| **操作类** | 回复长度微调、储备库开关、读工具激进度、降级偏好 | 角色可自调，前提是被授予 `config.tune_self` 授权边；每次自调写事件进审计；创建者可随时收回 |
| **人格类** | 外向度、话唠度、主动性、记忆权重 | **仅创建者**可调——这是"塑造"而非"运行"；角色自调视为越权（denial 可见） |
| **世界锁定类** | 人格类 + 会话级自治参数 | 世界 Owner 可 `canon_lock=true` 冻结整组参数，保证多人世界行为一致性；下层覆盖全部失效 |

默认意图：**角色管理自己的"运行方式"，不能改写自己的"性格"**。性格演化走正规通道：`card.propose` + 沙盒试演 + 创建者审批（03 §5），有证据、有审批、可回滚。

## 4. 自助调整流（产品形态）

- **用户**：设置页每项操作 = 一条身份流命令事件（设置即审计，可回放"你何时改过"）；
- **创建者**：角色详情页旋钮 = 带包络的滑杆组，改动即时生效，一键回滚任意历史版本；
- **角色**：`persona_config.tune` 命令 → 被世界/会话锁定 → denial 事件 → 决策协程"知道被拒"，甚至可以在戏里表达（产品趣味点，非缺陷）；
- **运营**：包络与平台默认经进程流发布；灰度 = 按 principal hash 分批生效。

## 5. 与其他模块的挂钩

- 准入点钳制（04 §5）；配额上限与 09 联动（配置不能突破配额）；
- 网关档位路由读取本配置（07 §5）；
- 提示板槽位预算即配置（12），Identity/Output 地板不可越；
- 客户端渲染滑杆所需包络经 API 下发（10 §5）。
