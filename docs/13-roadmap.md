# 13 · 路线图与验收

原则：每个里程碑以**可回放、可断言的场景**验收，不以功能清单验收。黄金场景测试全部基于"确定性重放 + 断言"（03 §9），进 CI 常驻。

## 1. 里程碑

### M0 基座（4–6 周）

| 范围 | 内容 |
|---|---|
| 执行内核 | loop 池、轮式调度、两车道队列、通道与背压（01） |
| 事件与存储 | 命令/事实两域、段文件、组提交 writer、快照、启动重放、幂等准入（04/05） |
| 领域最小集 | 主体、卡片版本链、会话、成员、权限链检查（02） |
| API 最小集 | auth、sessions（含读游标/未读）、messages、personas CRUD、瞬态信令 + WS 流（10） |
| 自治雏形 | 估分内核 + 决策协程 + 网关基础通路（单供应商） |

**退出标准**：重启不丢世界（快照+重放一致性断言）；段哈希链全量校验通过；两角色按脚本无人对话 30 轮（黄金回放）；1k 会话冒烟 p99 < 50ms。

### M1 自治完整（6–8 周）

| 范围 | 内容 |
|---|---|
| 自治完整 | 阈值校准、冷却、沉默事件化、语气储备、降级阶梯（06） |
| 记忆管线 | WorkingSet、晋升/去重/时效、审阅覆盖层（02 §5、03 §6） |
| 提示板 | 槽位预算制 + board_manifest（06 §3.0） |
| 配置面 | 分层合并、包络、三级自调（08） |
| 配额 v1 | 两层桶 + 租约 + 预留-结算 + 世界预算（09） |
| 导演基础 | pause/step/inject/rollback/explain（11） |
| 会话完善 | message.recall 撤回（标记式，04 §2）、commands 状态端点（10 §4.10） |
| 网关完整 | 优先级、熔断降档、批化归纳、饱和度闭环（07） |

**退出标准**：20 人会话 24h 无人值守不跑偏（锚点漂移评分 < 阈值的黄金断言）；世界 token 预算硬顶零突破（成本断言）；限流/耗尽/降级路径混沌演练通过；记忆重建后人工审阅覆盖完整保留（覆盖层断言）。

### M2 开放（8–12 周）

| 范围 | 内容 |
|---|---|
| 推演 | fork/flatten、祖先链记忆过滤、沙盒试演（03 §4–5） |
| 身份同步 | share.offered/accepted、binding 通知、persona.card_changed（03 §3） |
| 技能 | registry、工具技能、插件宿主（MCP 形态）、签名（12） |
| 开放 API | 第三方 service token、只读 + 显式回复网关（10 扩展） |
| 归档层 | PG tierer、历史深查询、冷段对象存储（05 §8） |
| 多节点 | shard 迁移跨节点、primary-backup 段复制（05 §7） |

**退出标准**：分叉推演可撤回且 flatten 校验通过；技能装配越权全 denial（合规演练）；外部开发者经只读 API 接入演练成功；节点 kill -9 接管 < 1s 且零事件丢失。

### M3 生态（12 周+）

| 范围 | 内容 |
|---|---|
| 市场 | 技能/世界模板发布审核流、二创血缘（12、03） |
| 商业 | 订阅档位 ↔ quota.granted、计费树对接（09 §7） |
| 串门 | Visit 协议：访客令牌、公开场景切片、回归摘要、审计（M2 契约、M3 实现） |
| 规模 | 多节点水平扩展压测至集群目标；移动端 WS 调优 |

**退出标准**：有付费世界与稳定创作者供给（商业指标）；集群线性扩展验证。

## 2. CI 评测闸门（贯穿所有里程碑）

| 闸门 | 内容 |
|---|---|
| 黄金回放 | 30 轮无人对话、锚点漂移脚本、多人群像脚本——重放 + 断言，任何 PR 不得破坏 |
| 确定性 | 同种子同输入 → 事件流逐字节一致（LLM 输出来自已记录输入） |
| 恢复矩阵 | kill -9 / 段截断 / PG 断连 / 磁盘满，逐项自动化演练（05 §6） |
| 成本 | 每世界 token 硬顶断言；预算反馈闭环收敛性测试 |
| 记忆质量 | 召回命中率、矛盾率、污染率、上下文节省率四指标回归 |
| 契约 | spec ↔ 处理器一致性 + 黄金请求/响应样例（10 §7） |

## 3. 风险与对策

| 风险 | 表现 | 对策 |
|---|---|---|
| 成本 | 多角色持续对话 token 膨胀 | 档位路由、批化归纳、配额硬顶、饱和度闭环（07/09） |
| 漂移 | 角色越演越偏 | 锚点槽地板、范例对白、黄金回放断言、card.propose 审批制 |
| 记忆污染 | 错误事实累积 | 去重/时效双闸、审阅覆盖层、删除级联、重放重建（02 §5） |
| 跑偏 | 角色无视世界规则 | Canon 槽高优先、canon_lock、导演暂停/回滚、护栏（06/08/11） |
| 安全 | 越界内容与未成年人 | Output 槽护栏、内容分级、审核与举报闭环（M3 公网前必须完备） |
| 冷启动 | 没有世界可逛 | 模板世界包（03 §7）、种子创作者运营（M3） |
| 平台依赖 | 单一模型供应商风险 | LLMProvider 多适配器、档位自动切换（07 §5） |

## 4. 迁移策略（工程顺序）

1. 先立骨架：CMake 模块 target、事件 codec、段文件读写、io_context 测试座——事件层先于一切；
2. 领域类型 + 准入协议 + 单会话端到端（一个 loop、一个会话、两角色、黄金回放测试跑通）；
3. 多 loop + 身份分片 + 网关域拆分（同进程多域）；
4. PG tierer 与归档查询；配置面与配额树；导演与 WS 完整协议；
5. 每一步保持黄金回放绿——任何阶段不允许"大爆炸式重写"。
