# 06 · 自治引擎

角色自主行为循环：感知 → 评估 → 意图 → 行动 → 反思。全部发生在会话 loop 上（I2），模型调用经由网关域（07）。

## 1. 总览

```
会话 loop（每 tick）                          模型网关域（独立 loop 池）
┌─────────────────────────────────┐          ┌──────────────────────┐
│ 感知 → 估分(数值内核) → 调度      │  submit  │ 优先级队列/配额/熔断  │
│   → co_spawn 决策协程            │ ───────→ │ 多供应商/成本台账     │
│   → 执行(命令事件) → 反思(背景道) │ ←─────── │ 饱和度信号广播        │
└─────────────────────────────────┘  reply   └──────────────────────┘
决策协程生命期 = 一次 deliberation，全程 co_await，不占线程；监管者包裹
```

## 2. 感知与估分：纯数值内核

感知输入 = **事实事件与 tick**；瞬态信令（输入中/在线等）不入流、不参与打分（01 §4.1）。

### 2.1 数据布局（零分配）

```cpp
struct ScoreScratch {              // 每 loop 一份，池化复用
    float energy[256];             // 成员上限 M=256，SoA 布局
    float affinity[256][256];      // presence 缓存，反思时更新
    float topic_sim[256];
    float streak[256];             // 连续发言计数（成本递增）
    // attention = dot(w, f) − cost；编译器自动向量化（AVX2/512）
};
```

超过 256 人的会话走候选分级（先按活跃度预筛）。

### 2.2 特征表

```
f_mention     被@/被引用/被回复 —— 解析期产出位掩码，取用零成本
f_topic       词汇重叠（日程关键词 ∪ 未完话题），BM25-lite
f_relation    affinity[X][author]
f_reciprocity 近期是否互转过
f_novelty     1 − 与近期窗口相似度（抑制复读刷屏）
f_urgency     事件等级（导演注入 > 用户消息 > 环境）
cost          递增成本 = base × (1 + streak×k) × 1/(0.2 + energy)
attention     = Σ wᵢ·fᵢ − cost + 噪声   （噪声种子 = hash(stream_id, tick)，可重放）
```

词汇相关度只做粗筛；borderline 带内且过其他门的候选才升级向量相关度（在决策准备期做，不进 O(M) 循环）。

### 2.3 阈值校准与冷却

```
τ_speak = τ_base × activity_factor(近期发言率 EMA) + mood_offset
  —— 热闹房间自动上调防刷屏；冷场房间下调防死寂；疲惫/低落 ↑τ
冷却：硬冷却 H 拍（不可发言）+ 软冷却（streak 抬高成本）
每拍最多 K 个决策协程（默认 K=2，配置面 08）
```

### 2.4 沉默的事件化

不是每次沉默都写事件。两条规则：

- attention ∈ [0.6τ, τ)（"差一点就说"带）→ 10% 采样记录；
- **被@却选择沉默** → 必记（叙事上有意义：客户端可展示"欲言又止"）。

## 3. 决策协议（Deliberation）

```cpp
// 生命期 = 一次决策；结束即销毁；无驻留角色状态
awaitable<void> deliberate(DeliberationCtx ctx) {
    // 1 装配提示板（槽位预算制，见 08/12）+ 快照 presence/卡片版本/canon
    // 2 预算闸：本会话本拍剩余 token？主体配额？不足 → 降档微决策
    // 3 co_await gateway.submit(req)   // 8s deadline；卸载/暂停 → cancel
    // 4 解析响应：
    //     纯内容        → speak 命令事件
    //     读类工具调用   → 执行 → 结果回填 → 重新提示（≤3 轮）
    //     改状态工具调用 → 翻译为命令事件（causality=决策事件）→ 入队 → 结束
    //     每轮复检预算，耗尽即收
    // 5 decision.recorded：attention 向量、卡片版本、引用记忆 ID、
    //   生效配置 ContentId、模型、token、成本
}
```

### 3.0 提示板（Prompt Board）：槽位与预算

装配不是"把检索结果拼进去"，而是按槽位与 token 预算取舍。总预算 = 目标模型上下文 × 预留系数（默认 0.8）：

| 槽位 | 内容 | 预算 | 策略 |
|---|---|---|---|
| Identity | 名字、描述、锚点、禁忌 | 12% | **地板锁死，不截断**（安全槽位） |
| Canon | 世界规则、当前场景 | 13% | 高优先 |
| State | 情绪、精力、关系、日程 | 8% | 高优先 |
| Memory | 事实 + 检索片段（02 §5.3 召回规则） | 25% | 超出按分数截断 |
| Recent | 最近 N 轮原文 | 22% | 超出从最旧开始截 |
| Skills | 已装配技能片段（12 §5 生效集） | 8% | 按装配优先级截 |
| Output | 输出格式与安全约束 | 12% | **地板锁死**（安全槽位） |

- 超预算降级顺序：Memory → Recent → Skills（Identity/Canon/State/Output 不到万不得已不动）；
- Memory 召回：关键词 + 向量双召回 → 重排 → MMR 去重 → scope 过滤；
- 每槽位实际 token 数写入 `decision.recorded.board_manifest`（可解释性）；
- 槽位预算比例属配置面（08 §2），但 Identity/Output 地板是平台包络，任何配置层不可越。

### 3.1 角色工具集（能力面 = 权限面）

| 工具 | 命令 | 权限注记 |
|---|---|---|
| speak / emote / react | message.append / react | 会话成员即可 |
| query_history | 读窗口/过滤 | 读权限；工具循环内使用 |
| dm_request(对象) | 发起单聊会话 | 对方可见性/关系门控；新会话 owner=发起者链根（默认策略） |
| invite(主体) | member.add | 需 Admin+ |
| card.propose | 提案改自身设定 | 需显式授权边；走沙盒试演（03 §5） |

### 3.2 超时降级阶梯（永不出现"死空气"）

```
0s 提交 → 8s 截止 → 超时/失败：
  第一级：语气储备库取一条预生成台词（fallback 标记入事件）
  第二级：沉默事件（分数已有）
熔断：每 tier×供应商 连续失败 → 切低档，半开探测恢复（07 §5）
```

**语气储备库**：会话空闲拍时网关用廉价档批量预生成每活跃角色 5–10 条情境台词（存 presence，KB 级，LRU）。高负载/供应商抖动时角色依然"在说话"，成本归零。

## 4. 反思管线（背景车道，滞后容忍）

| 任务 | 触发 | 执行 |
|---|---|---|
| WorkingSet 更新 | 每次 deliberation 后 | 规则为主：窗口滚动、话题开合、情绪轨迹 |
| 日程重写 | 每 N 拍或议程完成/失败 | 廉价档；输入 = 短期 + 长期召回摘要 |
| 关系更新 | 交互 sentiment 变化 | 启发式为主，廉价档抽查 |
| 场景摘要 | 每 30 轮 | **批化**：一次调用合并 K 个会话分段 |
| 事实抽取 | 每 10 轮异步 | 同上批化；SPO + 置信度 + 溯源 |
| 晋升/去重/时效 | 写入前 | Jaccard + 余弦双闸；冲突保留 valid 区间 |
| 重要度反馈 | 被引用 ↑ / 长期未召回 ↓ | 投影层定期重算 |

归纳类负载是最大 token 消耗方：一律批化、P3 优先级、配额闲时执行。滞后无害（派生层，重放可追平）。

**日程依赖短期记忆**：agenda 挂 WorkingSet，反思时用"短期 + 长期召回"重写。角色同属多会话时各有局部日程；跨会话主线连续性由长期记忆承担。

## 5. 与导演/确定性的交互

- **暂停** = 轮式调度摘除槽位 + cancel 在途环境档（P2）决策（预算返还）；交互档（P0）允许完成；
- **单步** = 手动投一拍；**回滚** = 事件流重放（11）；
- 重放确定性：打分噪声有种子；LLM 输出作为已记录的外部输入回放；任意一次自治行为可逐帧复现并展开解释。

## 6. 数值走查（20 人会话，tick 4s）

```
打分：20×12 特征点积，向量化 <1µs / 拍，零分配
期望发言：校准至 ~0.65 次/拍 → 每拍 ≤2 个决策协程（K 上限）
单次决策：prompt ~2.5k tok（含召回记忆）+ 生成 ~150 tok，环境档
百会话世界：≈16 次/s 决策 + 批化归纳 ≈ 每小时 ~1.5 亿 token
成本三旋钮：发言率(τ) × tick 周期 × 档位路由；配额桶给出硬上限；
  网关饱和度反馈闭环实时调节（07 §4）——预算是显式配置，运行时永不超过
```
